# Lumen — App Review Notes

Paste the relevant section into App Store Connect → "App Review Information" → "Notes" before submitting for review.

---

## Notes for the reviewer

**Lumen is a local-only cycle-tracking app.**

- **No login is required.** There is no account system, no sign-up, no email verification. The reviewer can launch the app and use the entire feature set immediately.
- **No demo account needed.** Because there is no account.
- **No network calls.** The reviewer can run Lumen in airplane mode and verify the app is fully functional without a server.
- **No third-party content.** All data is generated by the user on-device.

## Expected first-launch flow

1. Launch Lumen → Welcome screen ("Quiet, body-literate cycle tracking").
2. Tap **Get started** → Step 1: pick a date for your last period (or skip).
3. Step 2: review default cycle / period length (28 / 5).
4. Step 3: optionally enable reminders → tap **Open Lumen**.
5. Home screen shows the cycle ring and a "Quick log" bar. Tap any flow chip to log; tap the ring to open the full day-log.

Total time to a logged period: under one minute.

## Permissions

Each permission is requested **just-in-time**, never up-front.

- **Notifications** — requested only after the user enables a reminder in Settings → Reminders.
- **Face ID / Touch ID** — requested only after the user enables Settings → App lock.

The app remains fully functional if the user denies any permission.

## Data handling

- All cycle data, settings, medications, and notes are stored in a SQLite database in the app's sandbox.
- The encryption key is generated on first launch via `expo-crypto.getRandomBytesAsync(32)` and stored in Keychain via `expo-secure-store`.
- Lumen excludes its database from iCloud backup (`usesIcloudStorage: false` in `app.json`).
- Privacy nutrition label is "Data Not Collected" and that is genuinely true.
- Privacy policy: see "Privacy Policy URL" in the app listing.

## Health-related disclaimers

Lumen is **not** a contraceptive. The fertile-window estimate is computed from the user's cycle pattern using the standard luteal-phase assumption (ovulation ≈ 14 days before next period, fertile window ≈ 5 days before to 1 day after ovulation). The UI consistently labels this as an estimate, not contraception. Sample copy from the home screen:

> "Estimate based on your cycle pattern. Not a contraceptive method."

The app does not diagnose pregnancy or any medical condition. Pregnancy mode is a UI state activated by the user that pauses cycle predictions and counts weeks from a user-supplied last menstrual period.

## How to exercise key features

To skip onboarding and see realistic data, the reviewer can:

1. Complete onboarding once.
2. Settings → "Customize quick-bar" — observe configurable home-screen chips.
3. Settings → Mode → switch between Standard / Teen / Pregnancy / Perimenopause to see life-mode adjustments.
4. Settings → Diagnostics — observe the storage-stats screen (no data leaves the device).
5. Settings → Doctor report (PDF) — generates a 12-month summary PDF.
6. Settings → Share with partner — generates a 14-day, read-only HTML snapshot.
7. Settings → Calendar export (.ics) — downloads an .ics file with the next 6 predicted period windows.

## Age rating

12+. Sex log is **off by default** and lives behind an opt-in toggle (Settings → Logging options → "Sex & protection log"). With this default-off behaviour, 12+ is the appropriate rating. If toggled on, the only sexual content is two boolean fields ("Sexual activity today" and "Protection used") with no descriptions.

## Build size

- iOS .ipa: ~30-50 MB (depending on architecture-specific stripping)
- Most of the size is React Native runtime + bundled fonts (Fraunces + Inter from Google Fonts, two weights each).

## Supported devices

iOS 15.1 and later. iPhone and iPad. No Apple Watch companion in this version.

- [ ] Cold launch → onboarding → home screen with ring rendered.
- [ ] Log a period day; verify the cycle ring updates.
- [ ] Open the calendar tab; tap a date; verify the day-log modal opens.
- [ ] Open Settings → Privacy policy; verify in-app policy renders.
- [ ] Open Settings → Mode → Teen; verify a "Learn" tab appears in the bottom bar.
- [ ] Open Settings → Customize quick-bar; verify the chip selection screen.
- [ ] Open Settings → Delete all data; verify the confirm sheet (do not need to actually delete).
- [ ] Toggle airplane mode; verify the app is still fully usable.

## Known limitations the reviewer may notice

- **HealthKit / Health Connect**: the toggle is present but disabled in this build. Tapping shows an alert: "Health sync needs a custom Lumen build with the Health module enabled." This is intentional — production-ready HealthKit integration ships in a follow-up build.
- **Apple Watch / widgets**: not in this version.
- **Localization**: this build is English-only. Localization scaffold is in place; additional locales follow.
